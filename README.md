# WhatToEat Server

WhatToEat（App） / 对策选饭（Web） 的后端服务，为 Android、iOS 与网页客户端提供菜品及点评相关的数据接口。

## 主要功能

- 提供包含用户点评信息的菜品列表
- 接收并管理用户上传的菜品
- 处理菜品评分与评论的提交和查询

## 望周知
- 本项目为 WhatToEat（App） / 对策选饭（Web） 提供数据服务
- 请勿上传与校园食物无关亦或是非法的内容

> 项目目前还处于初始开发阶段...
